# Recommender Systems

This directory contains implementations and examples of recommender systems. Recommender systems are algorithms designed
to suggest items to users based on their preferences and behavior.

They are widely used in applications such as e-commerce platforms, streaming services, and social media.

## Projects

- [01_collaborative_filtering](01_collaborative_filtering)
    - Collaborative filtering approach using user–item interaction data.
    - TensorFlow-based implementation.
